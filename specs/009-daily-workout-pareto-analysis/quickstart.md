# Quickstart: Gráfico de Pareto Dinâmico por Treino

1. Abra o site no navegador (`https://hyrox-simulado-26d.web.app` ou build local).
2. Clique na aba **Analytics & Gráficos (7)** no menu de navegação.
3. Localize o cartão **Gráfico de Pareto para Eficiência de Exercícios**.
4. Observe que o gráfico agora inicia automaticamente no modo **Treino do Dia (Dia X)**, exibindo os exercícios específicos da sessão ativa.
5. Use o seletor de dias integrado para navegar entre qualquer um dos 26 dias (ex.: Dia 1 - Força, Dia 3 - Compromised 5 Rounds, Dia 8 - Pernas & Trenó, Dia 26 - Simulado Oficial).
6. Alterne entre **"Fadiga / Esforço"** e **"Tempo Gasto"** para analisar diferentes dimensões de desgaste.
7. Alterne para **"Simulado Oficial Completo"** se desejar a visão macro das 8 estações da prova de competição.
